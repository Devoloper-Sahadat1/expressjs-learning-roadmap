Lesson 01 — Express.js: What and Why?

The Problem

Consider a food delivery application. The frontend sends requests like:

GET /restaurants
POST /orders

The backend has to decide who receives each request, which route handles it, which function runs, how the response is shaped, and what happens on error. Node's built-in http module can do this manually — but routing, middleware, and error handling become repetitive fast as an app grows.

Express.js is a lightweight framework that organizes those concerns, so the focus shifts back to business logic.

Simple Analogy

Node.jsAn empty piece of land
VS
Express.jsA structured framework built on that land

You can build everything yourself on raw Node — Express just gives you practical structure and utilities for the common web-server work.
